# The geometry service's environment, pinned to what actually runs on the Thor.
#
# torch is deliberately NOT pinned to a wheel here: the aarch64 CUDA build for
# this box is installed by the platform image (torch 2.11.0+cu130), and the
# service is run from that venv. Everything else is pinned to the version that
# was measured on 2026-10-29.
#
#   torch==2.11.0          (from the platform image; +cu130)
#   torchvision==0.25.0
#
# Install:
#   uv pip install --python ~/ml/.venv-vggt/bin/python --no-deps -r geometry/requirements.txt
#
# `moge` and `utils3d_moge` are not on PyPI; both come from git. The `moge`
# package's own requirements pull in a large tree (gradio, triton, flex-gemm)
# that the service does not use, so it is installed with --no-deps and the
# parts the service needs are listed here.
#
# The weights are not a dependency: they are a 1.26 GB model, and they live
# outside the repository at ~/models/moge-vitl/model.pt
# (Ruicheng/moge-vitl, MIT).
