# Facts are per-attribute rows resolved by rank, then confidence, then time

A **Fact** is one row: `(featureId, attribute, value, source, confidence, observedAt, version)`. Several Facts may exist for the same `(featureId, attribute)`, one per source. The _resolved_ value is the Fact with the highest source rank (`osm` < `overture` < `satellite_inference` < `street_imagery` < `capture` < `manual_edit`), then the highest confidence, then the latest `observedAt`, then the highest `version`. Re-writing a Fact from the same source bumps `version` and replaces the previous value for that source; history beyond that is out of scope for M0. Geometry is a Fact too (`attribute: "footprint"` for areas, `"path"` for lines, `"position"` for points), so geometry carries provenance like everything else.
