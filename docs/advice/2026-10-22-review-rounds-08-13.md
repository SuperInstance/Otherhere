## Fix first (Arc 0 is not done)

Each fix is one small PR, with a test that fails before it and passes after.

### P0

1. **Reloading a loading Cell still leaks its wake** (`apps/client/src/world.ts:695–701`). `reload()` passes `s.wake` on only in the `group` branch. The `else if (s?.stale)` branch drops it.
   - _Scenario:_ a ready Cell is waking. A first reload moves the wake into the loading state. A second reload comes before that load lands. The wake material is never disposed, and `advanceWakes` stops tracking it.
   - _Test:_ two reloads before the first load resolves, while a wake is active.
2. **The stale-`seeked` guard does nothing in real browsers** (`apps/client/src/capture.ts:56`). Chrome and Firefox set `currentTime` to the new target as soon as it is assigned. A late `seeked` from the timed-out seek therefore sees `currentTime ≈ target` and settles the wrong seek. The fake video in the test only updates `currentTime` when the seek lands, which real browsers don't do.
   - _Do:_ give each seek a token, or settle only when `!video.seeking`.
   - _Test:_ make the fake update `currentTime` on assignment, the way browsers do.
3. **Lookup tables shape output but are not in the content address.**
   - The tables: `REGION_PRIORS` and `GENERIC_PRIOR` (`packages/core/src/essence/region.ts:33–50`), and `FOREST_BIOMES` and `RAINFOREST_BOX` (`packages/core/src/forest/species.ts:76–100`). The `FOREST_BIOMES` mix is written into the GLB extras (`bundle/build.ts:185–195`).
   - Only the region _code_ is hashed. The comment at `build.ts:74–75` says the table "is interpreter code, whose version is in the address". That holds only by convention.
   - _Scenario:_ someone edits a wall colour. R2 keeps serving the old GLB under the old hash. The client rebuilds it with the new code, gets different bytes, and shows fewer than n/n verified.
   - _Do:_ hash the tables' canonical JSON into the address, or a `TABLES_VERSION` pinned by a test that fails when a table changes without a bump.

### P1

4. **The region overrides the size rule** (`packages/core/src/generators/building.basic.json:266–310`). The region branch runs before the house / small-`yes` rule. So every unknown building in Southeast Alaska, of any size, is pitched 8 times in 9: a 3,000 m² cannery gets a gable. Your PR says larger ones keep flat or hip, but the large-building test (`region.test.ts:216`) runs only without a region.
   - _Do:_ gate the region's roof weights on footprint. Add an in-region large-building test.
   - It's a generator change, so bump the version and re-pin the golden.
5. **The postcard pixel bound is one CI measurement** (`e2e/postcard.spec.ts:136`, limit 496). There is still no root cause, and the measured difference went up from 172 to 496 after the scene-clock change. Find the cause (uniform precision across contexts is the lead from the last review), or measure 10 runs and set the bound from their spread. Write the numbers in the PR.
6. **The wind wrap limits the jitter but doesn't remove it** (#65).
   - At an 11,200 s period, `sin` still sees arguments near 7e4 rad, where float32 steps are about 0.008 rad. Wrap per term, or choose a period the shader's rates divide.
   - `sceneTimeU` (ocean, foam, mist, stars; `main.ts:286`) is not wrapped at all.
   - The e2e check `t2 ≤ 11200` (`walk.spec.ts:135`) passes without the fix.
7. **The crown law can't pin the shader** (`e2e/crown.spec.ts:107,125`). It compares only how far the crown moves, not which way, within `1.2 + 0.25·pred` px. Wrong direction passes. Half amplitude passes. A frozen crown passes whenever the predicted movement is ≤1.6 px.
   - _Do:_ compare signed displacement along the wind axis. Then stop: this instrument is finished. Spend no more rounds on wind.
8. **The live region turns back into a counter on mismatch** (`apps/client/src/status.ts:66–71`). When anything mismatches, the `verified/ready` line moves into the `aria-live` `#status` and is re-announced on every Cell that lands. Announce the mismatch once.
9. **Comments that are still wrong** (from the last review, item 9, still open):
   - `sky.ts:11` says "never the wall clock";
   - `cloudOf` reverses the haze calculation (`atmosphere.ts:250,263–264`);
   - "Zürich renders exactly as before" in #77. House weights changed worldwide.
   - "the derived region always equals the stored one": `build.ts:79` uses the Cell's centre, while the Town DO uses the Town's.
   - "stops at the Alaska–BC line": the box at `region.ts:57` reaches Stewart, Atlin, Carcross and Teslin.
